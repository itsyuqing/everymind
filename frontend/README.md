# 988 Insights — React frontend

React + TypeScript + Tailwind CSS (v4) + Vite. It reads the data that `run_pipeline.py` produces.

## Run it
```bash
# 1. From the project root (everymind/), build the data (any time the survey export changes)
python run_pipeline.py data/survey_raw.xlsx        # writes output/dashboard_data.json

# 2. Set up and start the app
cd frontend
npm install          # first time only
npm run make-map     # first time only: creates src/data/md-dots.json (the Maryland map)
npm run dev          # opens http://localhost:5173 with live reload
```

## Build a shareable file
```bash
npm run build
```
This produces **`dist/index.html`**: one self-contained file with all code, styles and data inlined.
Double-click it to open it in any browser (no server needed).

## How the data gets in
`npm run dev` and `npm run build` first run `scripts/sync-data.mjs`, which copies
`../output/dashboard_data.json` into `src/data/`. So the update workflow is:
**new Forms export → run the pipeline → `npm run build`**.

## Structure
```
src/
  lib/data.ts        decodes the pipeline JSON into typed rows
  lib/metrics.ts     metric definitions (mirror summarize() in run_pipeline.py)
  components/        Layout (sidebar, top bar), FilterPanel + chips, CountyMap, charts, ui primitives
  pages/             Overview, SessionExplorer, Other (Comments, Data Quality)
  data/md-dots.json  Maryland dot-map, generated by `npm run make-map` from US Census county shapes (us-atlas)
```

## Pages
- **Session Explorer**: filter panel (staged, applied with *Apply Filters*), filter chips, a clickable county dot map, and a table of every training session with sorting and *Load More*. Session status comes from NPS: Strong ≥ +30, Mixed 0 to +29, Needs attention < 0, and Small sample under 30 responses.
- **Overview**: KPI cards with monthly sparklines, auto-generated insights, before/after learning, knowing-vs-calling, group comparison, and trends.
- **Comments**: theme bars for "most valuable" and "how to improve".
- **Data Quality**: the full cleaning log, plus method and limitations.

Privacy: groups under 10 responses are hidden, under 30 are flagged, and no free-text comments are included.

## Troubleshooting
- **"Missing dashboard_data.json"**: run the pipeline from the `everymind` folder first (step 1).
- **"Cannot find module '../data/md-dots.json'"**: run `npm run make-map`.
- **"Cannot find module 'react'"**: run `npm install` inside `frontend`.
